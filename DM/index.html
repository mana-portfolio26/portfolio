PLANNING

英国フェスとレストランを 融合した空間演出

クライアントからは、 イギリスの野外フェスの空気感と、 レストランのような上品で洗練された空間を 映像で表現してほしいという依頼を受けました。

制作前には会場レイアウトを確認し、 LEDスクリーンのサイズ・位置、 ステージ構成、 来場者導線を把握しながら 映像演出全体を企画しました。

LEDならではの高い発色を活かし、 シンプルながらも高級感を感じられる ビジュアルデザインを目指しました。

SETUP

LED Installation

本イベントではLEDスクリーンを使用した 映像演出を担当しました。

LEDスクリーンのサイズや画角を考慮しながら、 映像が最も美しく見えるようレイアウトを設計しました。

プロジェクションマッピングのような見え方になるよう、 LED画面内にフレームを制作し、 映像をリアルタイムで切り替える構成を企画しました。

設営・本番オペレーション・撤収まで、 すべて一人で担当しました。

CONCEPT

上品さとクラブカルチャーを 映像で融合する

Resolume Arenaでは 3レイヤー構成でライブオペレーションを実施。

LED画面内へ額縁のようなフレームを構成し、 映像だけを切り替えることで プロジェクションマッピングのような 奥行きを感じられる演出を制作しました。

クラシックな装飾と モダンなモーションデザインを組み合わせ、 イギリスのフェスカルチャーを感じられる 空間演出を目指しました。

VISUAL DESIGN

AIと映像デザインを 組み合わせたLED演出

映像素材はAIも活用しながら制作しました。

上品さ・レストラン・イギリスカルチャーを テーマにデザインを構成し、 クラシックな質感と現代的なモーションを 融合しています。

Resolume Arenaによるリアルタイム操作で、 楽曲に合わせて映像を切り替え、 ライブならではの映像演出を行いました。

LED VISUALS

Visual Design

イギリスの野外フェスと、 レストランのような上質な空間をテーマに制作した映像素材です。

LEDスクリーン内にフレームを構成し、 映像を切り替えることで、 シンプルながら立体感のあるライブビジュアルを制作しました。

LIVE VISUAL

LED Performance

本番ではResolume Arenaを使用し、 楽曲の展開や会場の空気感に合わせて リアルタイムで映像をオペレーションしました。

REFLECTION

LEDならではの空間演出を 一人で完成させたプロジェクト

本プロジェクトでは、 会場確認・企画・映像制作・AIビジュアル制作・ LED演出・設営・本番オペレーション・撤収まで、 すべて一人で担当しました。

LEDスクリーンの特性を活かし、 レストランのような上質な空間と クラブカルチャーを融合した映像演出を実現しました。

また、本番では映像だけではなく、 ライティングスタッフ・レーザー演出との バランスを考えながら映像を調整しました。

LEDスクリーンは光量が強く、 映像の明るさや色味によって 照明やレーザーの印象が大きく変化します。 そのため照明スタッフと細かく連携し、 空間全体が最も美しく見えるよう 映像をリアルタイムで調整しました。

映像制作だけではなく、 他セクションとのコミュニケーションや 現場で状況を判断・改善する力を養い、 空間全体を演出する視点を身につけることができました。
